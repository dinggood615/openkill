# 兼容设置与 VPN / 远程访问

## 页面入口

服务 → OpenKill → 插件设置 → 兼容设置。它位于“系统维护”前；原“系统与维护”更名为“系统维护”。

## 本版实际实现

- 集中展示 VPN 推荐策略、服务端口绕过、目标地址/端口绕过、旁路由兼容。
- 服务端口开关和列表连接实际 UCI / firewall4 运行逻辑，不是只有界面。
- 服务端口绕过默认关闭，升级迁移会主动关闭旧版的宽泛端口集合。只有确认旧版 firewall4 兼容需要时才启用；启用且列表为空才沿用 1194、9993、21114 至 21119。填写后替换默认值；关闭开关则清空专用绕过集合。
- “兼容策略”默认是“稳定兼容”，由 OpenKill 统一管理 TUN、DNS 和防火墙；“高性能双栈”仍由 OpenKill 接管，但会启用 TCP 并发、统一延迟、标准 Geo 数据加载，并保持严格路由和端点独立 NAT 关闭；“Mihomo 原生接管”才启用 `auto-route`/`auto-redirect`。三者不可同时启用。高性能档会增加内存占用，低内存设备应使用稳定兼容。
- 原生接管预检失败时不会留下半套规则：服务会回退到 OpenKill 管理并记录 `fw4-native-unavailable`，运行状态显示“稳定兼容（原生回退）”；修复 fw4 后重新启动即可再次尝试原生接管。
- “代理出口接口”默认自动识别有默认路由的真实出口，并排除 tun0、utun、ZeroTier 和 Docker 等隧道/覆盖接口；同时兼容 IPv4/IPv6 默认路由。PPPoE/DHCP 未获得默认路由时会延迟启动，避免 DNS 绑定到已经消失的虚拟接口。固定模式只填写真实 WAN 设备名；二级路由只有在 br-lan 确实是上游默认出口时才填写 br-lan。
- 目标地址/端口和旁路由兼容沿用原有实现，只移动入口，不重置用户配置。
- 本次不修改路由器、OpenVPN 配置或私人 YAML，不开放 WAN 入站端口。

## 最终推荐方案与边界

采用“隧道外层连接直连、局域网业务直连、VPN 客户端公网流量按规则分流”。不要把整个 VPN 客户端源网段加入来源绕过，不要排除整个 tun0。

固定服务端口绕过仅适用于 OpenKill 统一管理 / firewall4，按 TCP/UDP 源或目标端口匹配，可能影响使用相同端口的其他业务，属于兼容过渡措施。它不等于精确的服务自动识别；原生接管和 firewall3 不使用这套专用端口集合。

更精确的后续实现应在确认实际服务端点后，按地址、协议和端口组合区分 OpenVPN 隧道外层、RustDesk 服务端与客户端业务。自建服务使用动态域名时，需要把域名直连与 Fake-IP 过滤联动、维护解析结果的更新与过期清理。上述自动识别、域名联动尚未实现，不应仅靠当前页面宣称解决。

## 安装后的详细操作

1. 备份 OpenKill 设置和原有配置，按 README 一键指令更新。刷新页面；仍显示旧标签时强制刷新浏览器。
2. 打开“兼容设置”，确认“系统维护”位于其后。
3. 优先保持“稳定兼容”模式。默认不启用旧版服务端口绕过，避免宽泛端口规则把 RustDesk、OpenVPN 或其他业务拆成直连/代理两条路径。
4. 只有确认旧版 firewall4 兼容需要时才开启端口绕过；核实 OpenVPN 的实际监听端口、RustDesk 的实际服务器地址与端口。仅填写真实使用的端口；9993 常见于 ZeroTier，不使用该服务时不必保留。不要把所有 443 流量作为通用解决办法绕过。
5. 已知需直连的固定服务 IP，可加入“目标地址绕过列表”，只填必要地址/网段，不填整个互联网。此项输入是 IP / 网段，不是域名；Fake-IP 域名需要额外过滤，当前没有自动联动。
6. 普通主路由不要因 VPN 故障盲目开启“旁路由兼容”。不要改变 VPN 默认路由或 DNS 推送，除非实际检查证明配置错误。
7. 保存并应用，确认 OpenKill 已重新生成规则；运行状态页会显示当前策略。若页面提示需要重启，再执行一次 OpenKill 重启。若 WAN 正在拨号，等待默认路由就绪后再启动。操作可能中断连接，应从局域网管理或保留备用管理路径。
8. 从真正的外部网络连接 OpenVPN，分别测试路由器管理页、LAN 设备、国内网站、需要代理的网站。检查连接面板中的规则命中与代理链；不能仅以网站可打开断定经过 OpenKill，因为上级路由可能已经代理。
9. 分别测试 RustDesk 局域网连接、外网连接和持续传输；观察断流、延迟和 CPU。IPv4、IPv6 分开验证；隧道外层使用 IPv6 不代表客户端隧道也承载 IPv6。
10. 若异常，撤销本次新增列表或恢复备份并重新应用，保留内核日志及实际端点信息再定位。不要直接对 WAN 全放行，也不要关闭整体防火墙。

## 验收范围

本地自动测试覆盖页面顺序、字段映射以及端口开关/默认/自定义/非法输入处理。软路由实机连通性、原生接管、firewall3 和各服务的端到端兼容性需分别验证；发布成功不代表这些实机验证已经完成。

# OpenKill 2026-1160

## NaiveProxy independent bridge

- NaiveProxy nodes, protected JSON configuration, procd instances, loopback
  SOCKS5 listeners and HTTPS health results now belong to the standalone
  `naiveproxy-bridge` service under `/etc/naiveproxy` and `/var/run/naiveproxy`.
- OpenKill no longer installs, starts, stops, probes, stores credentials for,
  or injects NaiveProxy nodes into Mihomo. Its compatibility page reads only a
  redacted manifest and provides a credential-free SOCKS5 YAML snippet for
  manual insertion into `proxies` and `proxy-groups`.
- Existing OpenKill NaiveProxy UCI/YAML data is retained for migration and is
  not deleted or silently converted to DIRECT. Old routes redirect to the
  compatibility page or return read-only standalone status.

## Verification limits

Local POSIX syntax, standalone fixture, integration contracts, UI contracts,
`git diff --check` and `scripts/local-gate.sh` passed. Device installation,
real VPS authentication, packet-path tests and browser rendering were not run
in this release and must be verified separately.

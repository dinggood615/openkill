# OpenKill 2026-2001

本版本聚焦 LuCI 页面归类、来源规则编辑体验和运行状态卡片契约；不改变 DNS、NaiveProxy、WAN、路由、TUN 或其他网络策略。

## 页面与来源流量规则

- “来源流量规则”使用稳定的 `lan_ac_traffic` CBI 标识挂载到“流量转发”卡片，避免依赖翻译后的标题或主题 DOM 猜测。
- 保留原 UCI section、字段名、顺序、校验、排序、增删改和提交行为；规则行以响应式纵向卡片呈现，桌面两列、窄屏一列。
- 空的“流量转发”普通字段仍保留规则挂载卡片，避免规则编辑器退回页面根部形成宽表。

## 运行状态卡片

- DNS 隐私、广告拦截、OpenVPN、RustDesk、NaiveProxy 统一为真实证据驱动的二元显示：可靠生效为“已开启”，明确关闭或未生效为“已关闭”。
- 首次没有状态接口时保留加载占位；轮询失败保留上次可靠结果并标记可访问的诊断信息，不再显示常驻“部分功能状态尚未确认”横条。
- OpenVPN 卡片表示兼容规则已应用，不再错误要求 VPN 隧道建立；NaiveProxy 仍独立依据组件、实例和本机 SOCKS5 就绪状态。
- 卡片标题、间距和断点按容器宽度统一，宽屏五列、中等宽度三列、窄屏两列/一列，避免标题被硬拆。

## 验证边界、升级与回滚

本版本已通过本地运行时、LuCI 合同、浏览器模板/交互和安装器门禁；页面行为证据为本地生产模板和虚构状态夹具。根据仓库当前 `AGENTS.md`，设备访问、真实 LuCI 会话、包安装和实际浏览器视觉验收在本次迭代禁止执行，因此不能将本版本描述为已完成测试机安装验收。

升级前备份 `/etc/config/openkill`、用户 YAML、来源规则和独立组件数据。升级失败时安装上一正式版 `v2026-2000-ipk` 并恢复备份；保留旧标签和 Release，不覆盖历史产物。

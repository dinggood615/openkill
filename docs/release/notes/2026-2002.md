# OpenKill 2026-2002

本版本在 `2026-2001` 的 LuCI 规则卡片和运行状态修复上补充来源规则字段标签，确保纵向编辑卡片在不同主题下仍能识别每个输入。

## 页面修复

- “来源流量规则”仍通过稳定的 `lan_ac_traffic` CBI 标识挂载到“流量转发”卡片，不依赖翻译标题或主题 DOM 猜测。
- 每条规则保留原 UCI 控件和提交名称，桌面两列、窄屏一列，并为备注、启用、来源地址/端口、协议、地址族、接口、用户、DSCP、处理对象、排序和操作显示明确字段标签。
- 五项运行状态卡片继续只显示可靠的“已开启/已关闭”结果；失败时保留上次可靠值或初始占位，不显示常驻未确认横条。

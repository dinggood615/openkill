# OpenKill 2026-1147

本版本将 NaiveProxy 组件接入 OpenKill 一键安装流程。安装器会按当前
OpenWrt 架构读取官方资产元数据，绑定 URL 与 SHA256 后执行暂存、校验和
可回滚安装。元数据或组件失败时 OpenKill 本体仍可独立运行。

NaiveProxy 节点继续由兼容设置页面录入或导入；启用节点后生成受保护的
辅助配置和回环 SOCKS5 入口，并向 Mihomo 输出 `type: socks5`、`udp: false`
的桥接节点。远端连接和设备行为需要在目标设备上单独验证。

上一版本 v2026-1146-ipk 保留作为回滚版本。

# OpenKill 2026-1162

## 变更

- 移除已退役的 OpenKill NaiveProxy 辅助脚本、旧状态页和自动 YAML/策略组写入路径。
- 将组件检测、节点操作、逐节点健康状态和手动 SOCKS5 片段统一到 NaiveProxy 独立服务卡片；旧书签保留为只读兼容入口。
- 一键安装在安装 OpenKill 后解析并校验官方 NaiveProxy OpenWrt 制品，检查 HTTPS 来源、大小、SHA256、归档、ELF 架构和本地版本探测；失败保留旧组件且不影响 OpenKill 主体。
- 新安装不再创建旧 `naive_*` UCI 默认项；升级保留旧值作为迁移证据，不删除用户节点、凭据或 YAML。
- OpenKill 不保存 NaiveProxy 凭据、不启动独立实例、不自动注入 Mihomo；用户继续将不含凭据的 `127.0.0.1` SOCKS5 片段手动加入 YAML 和策略组。
- 重写代理列表时保留已有的用户管理回环 SOCKS5 条目，避免独立服务节点被覆盖。

## 验证边界

本版本已通过本地独立服务、安装器、运行时、LuCI 合同、POSIX 语法和仓库门禁。真实设备、浏览器渲染、VPS 认证及数据包路径未在本批执行，升级后请先在设备上备份并按独立服务页面迁移旧节点。

# OpenKill 2026-2011

## 严格 DNS 的受管出站组

- 严格 DNS 的专用组由手动选择改为不含 `DIRECT` 的有界故障转移组，使用核心健康探测在有效成员之间切换。
- 保留原有代理节点、provider、用户规则和业务直连语义；没有可用成员时仍失败关闭，不回退到明文或 `DIRECT`。
- 启动就绪检查增加有限等待，以覆盖健康探测从失效成员切换到有效成员的窗口；持续失败仍拒绝报告服务就绪。

## 国内业务分流与广告屏蔽

- rule 模式在没有用户显式中国域名/IP决策时继续补入幂等的国内直连规则，严格 DNS 传输不再改变业务出站。
- 广告屏蔽继续使用同一份经 HTTPS 校验、规范化和原子替换的域名列表生成 dnsmasq 与 Mihomo 视图，允许列表和失败保留行为不变。

本版本不包含节点、订阅、密码、控制器密钥、用户 YAML 或设备专用数据。升级和重装保留用户配置；全新安装使用设备无关的通用默认值。

# OpenKill 2026-1148

## NaiveProxy bridge mode

- Added an explicit NaiveProxy bridge mode in Compatibility & Auxiliary:
  automatic Mihomo injection (recommended) or self-managed YAML snippets.
- Both modes keep the same protected helper configuration and loopback
  SOCKS5 lifecycle; self-managed mode does not inject a duplicate proxy into
  the generated profile.
- The bridge status now reports the selected mode while keeping credentials
  out of the preview.

Validation: local NaiveProxy integration, installer tests, POSIX checks,
`scripts/local-gate.sh`, Development CI and RC/Formal Release gates.
Device and remote Naive endpoint validation remain pending.

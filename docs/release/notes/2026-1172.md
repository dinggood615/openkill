# OpenKill 2026-1172

## 变更

- 补充本地 Playwright 浏览器测试的依赖诊断与隔离安装说明，明确区分
  Python 包、Chromium 运行时和 Linux 共享库缺失，避免把环境限制误报为
  页面测试通过。
- 记录并验证生产模板的真实浏览器交互：深浅色状态、响应式视口、请求竞态、
  键盘控件、配置编辑器状态和本地请求边界均通过；运行时依赖只放在开发缓存，
  不进入 OpenKill IPK。
- 保留 NaiveProxy 独立服务、节点凭据隔离、手动 SOCKS5 YAML 接入和现有
  OpenKill 配置语义；本版本没有自动修改用户 YAML、订阅、DNS、路由或策略组。

## 验证边界与回滚

- Windows 与 WSL 的真实浏览器预览均通过；NaiveProxy 导入、独立服务、POSIX
  语法、UI 合同、UI 交互、UI 预览、`local-gate` 和差异检查通过。
- 未执行测试机写入、独立组件安装、真实 VPS 认证、WAN/DNS、中央 nft 或数据包
  路径测试；这些仍标记为设备/远端待验证。
- 如需回滚，安装上一版 `v2026-1171-ipk`，保留现有节点、凭据和手动 YAML。

# OpenKill 2026-2022

## Telegram connectivity regression

- An enabled source-traffic rule with no source selector could expand to a
  global `RETURN` rule and bypass the proxy mark path. Runtime generation now
  skips such unscoped rows, while explicitly scoped rules retain their
  behavior.
- The LuCI help text now explains that at least one source address, source
  port, interface, user, or DSCP selector is required. This keeps the access
  control page simple and prevents an empty row from silently disabling proxy
  routing for LAN applications.
- Existing UCI values are preserved; only the invalid unscoped row is ignored
  until the user adds a selector or disables/removes it.

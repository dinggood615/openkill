# OpenKill 2026-2023

## NaiveProxy multi-node integration and diagnostics

- Adds an explicit managed integration path from an independently running
  NaiveProxy instance into a user-selected existing Mihomo proxy group. It
  does not change the default group or the user's routing policy.
- Makes node saving transactional and reports actionable failure categories;
  failed saves preserve the prior node data. Strategy-group loading now
  distinguishes an empty result from configuration, permission, or parse
  errors and provides retry feedback.
- Clears the raw share-link input after parsing and keeps credentials out of
  Mihomo YAML and status responses.
- Replaces implicit plaintext public DNS bootstrap with bounded HTTPS DoH
  bootstrap using hostname/SNI and certificate verification. Bootstrap
  failure does not silently fall back to plaintext DNS or replace the previous
  valid node configuration.

## Verification scope

Local behavior tests, the repository quality gate, exact-commit Development
CI, and the RC package audit passed for the implementation. Per the user's
requested order, formal publication precedes real-device import of the second
user-provided node and two-channel traffic acceptance. Those device checks are
pending and are not represented as passed in this release. Existing device
configuration and independent NaiveProxy data are preserved; only explicit
user selection adds a managed endpoint to an existing proxy group.

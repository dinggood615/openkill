## NaiveProxy 状态诊断与紧凑界面

- 手动 YAML 模式下，`final-yaml-missing-node` 只表示用户尚未把本地
  SOCKS5 片段放入自管 YAML，不再与辅助链路探测结果混为同一故障。
- 节点健康状态继续只通过对应 `127.0.0.1` SOCKS5 入口探测；Mihomo/YAML
  是否包含节点保留为独立只读诊断，不失败直连。
- 组件 URL、SHA256、制品详情、维护操作和详细诊断移入可展开区域；默认
  页面只保留组件状态、节点操作、辅助链路状态、延迟和复制入口。
- 连通性表移除重复的 Mihomo 常驻列，详情中仍保留最终 YAML、策略组、
  辅助进程和失败阶段；手机端改为无横向滚动的节点卡片。

# OpenKill 2026-1176

## Changes

- Repair the independent NaiveProxy link path for omitted HTTPS/QUIC ports,
  literal plus signs in credentials, URI validation and ambiguous IPv6 input.
- Avoid assigning newly imported nodes to a port already occupied by another
  listener; expose listener ownership and port-conflict evidence in the
  redacted manifest.
- Make the independent service wait for a matching NaiveProxy process and
  loopback listener before reporting a node start as successful. Health checks
  reject a listener identified as another process.
- Improve the NaiveProxy LuCI card with a visible component-to-Mihomo flow,
  transport and process/listener state, explicit port-conflict messaging, and
  a separate unverified Mihomo integration state.

## Validation scope and limitations

Local import, standalone fixture, integration-contract, POSIX syntax and
project quality-gate checks pass. The fixture covers default port 443 and
literal `+` credentials. No router write, service start, packet-path test or
authenticated remote Naive endpoint test was performed in this release.
The UI browser runner is environment-dependent on the Windows host; the
production template contract remains covered locally. Existing releases and
tags are retained for rollback.

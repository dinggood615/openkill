# OpenKill 2026-1134

## Changes

- Move the NaiveProxy component controls, status contract and operations into
  Plugin Settings → Compatibility. The former dedicated NaiveProxy URL now
  redirects to that single editor, so `naive_*` values cannot diverge between
  pages.
- Add an explicit official-release metadata check. It maps the local OpenWrt
  CPU family to an `openwrt-*` asset, requires the GitHub asset SHA256 digest,
  caches release metadata for six hours, and fills only empty URL/SHA256
  fields when the user clicks the detection action. It never installs,
  enables a node or restarts OpenKill implicitly.
- Add a scoped responsive component card with source, architecture, release,
  asset size, digest state, install/remove actions, timeout handling and
  conservative local/remote status wording.

## Migration and compatibility

- NaiveProxy remains optional and disabled by default. Existing nodes,
  subscriptions, Mihomo rules, DNS privacy, adblock, IPv4/IPv6 bypass,
  RustDesk and OpenVPN behavior are unchanged.
- User-entered component URL and SHA256 values are preserved unless an
  explicit replacement is requested. Unknown CPU families, missing official
  assets/digests, API errors and unavailable `jsonfilter` fail closed.
- Installation still uses the existing official HTTPS allow-list, size and
  archive checks, ELF/loader probe and atomic replacement. The bridge remains
  loopback TCP SOCKS5 with `udp: false` until a separately verified UDP path
  exists.

## Validation scope and limitations

- Local NaiveProxy integration, UI contract/preview, JavaScript syntax, POSIX
  syntax, metadata fixture matching and `scripts/local-gate.sh` passed from
  the pre-change master baseline. The exact source commit also passed
  Development CI.
- The official metadata source is the
  [NaiveProxy GitHub release API](https://github.com/klzgrad/naiveproxy/releases);
  a release asset digest is treated as an integrity fact for that asset, not
  as an independent signature. A real OpenWrt device, compatible binary
  loader and remote NaiveProxy server were not exercised in this release.
- Retain the previous `2026-1133` release and device backups for rollback.

# OpenKill 2026-2004

## 本次变更

- 统一插件设置七个子页面的内容自适应卡片节奏，减少无意义留白并保持桌面、窄屏和主题切换下的对齐。
- 修复来源流量规则的延迟挂载：规则区始终进入“流量转发”卡片，使用稳定标识和有界重试，不复制原生 CBI 控件。
- 将来源规则显示为纵向编辑卡片，完整保留备注、启用、来源地址/端口、协议、地址族、接口、用户、DSCP、处理动作及排序删除操作。
- 一键安装使用经过审计的通用 `performance-dual-stack` 初始配置；不携带节点、订阅、密码、用户 YAML、设备地址或个人规则。升级和重装继续保留用户配置。

## 升级说明

普通升级或同版本重装会保留现有 `/etc/config/openkill` 及独立组件数据。全新安装仅写入通用默认值；缺失的新字段由幂等归一化补齐。正式包安装前应保留设备配置备份。

## 验证范围

本版本包含本地 LuCI 合同、预览、交互和浏览器静态检查；候选包需在授权测试机复验七个设置页、来源规则编辑及配置保留后再正式发布。

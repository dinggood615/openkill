## 启动前置校验与 NaiveProxy 兼容性

- 修复 YAML 生成失败后仍继续检查旧文件的问题；控制器监听地址和端口
  现在在生成前统一校验，失败会保留当前可用配置并记录明确的启动阶段。
- 严格 DNS 隐私继续保持失败关闭，但会识别显式代理、代理提供者和
  `include-all` 组；没有可选代理组时给出可执行的配置提示，不再产生
  次生的“控制器监听器无效”误报。
- NaiveProxy 组件状态增加本地版本探测，旧版 `tls` 传输值兼容为 HTTPS，
  空凭据不会生成辅助配置；辅助进程退出与远端探测失败在节点状态中分开
  展示，仍只维护 `127.0.0.1` SOCKS5，不自动改写 YAML 或回退 DIRECT。

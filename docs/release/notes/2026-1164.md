# OpenKill 2026-1164

## 变更

- 修复 NaiveProxy 分享链接导入：支持 HTTPS 别名、IPv6、百分号编码凭据和节点名；前端预览与独立服务端会分别校验，未知参数不会静默丢弃。
- 修复组件状态误导：页面不再把已登记的路径显示成可用组件；现在会区分文件缺失、不可执行和加载器/版本探测失败，并给出下一步。
- 将 ZeroTier 现有字段迁移到“兼容与辅助 → 远程访问绕过”，原 UCI 字段、默认值和应用行为保持不变。
- “系统维护”保留在系统维护页，并占用原 ZeroTier 卡片位置，与 Mihomo 能力卡片保持等宽排列。

## 验证边界

本版本通过独立服务导入、百分号编码、UI 合同、POSIX 语法和 Development CI。真实设备、VPS 认证及浏览器渲染仍未在本批执行；组件状态需在设备上刷新或重新安装后确认。

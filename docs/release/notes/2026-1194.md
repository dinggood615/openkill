# OpenKill 2026-1194

## 修复

- 修复 Mihomo Fake-IP DNS 环境下独立 NaiveProxy 误把上游域名解析到 `198.18.0.0/15`，导致 TLS 握手失败的问题。
- 生成运行配置时使用有界的直接 DNS 解析，为上游域名写入官方 NaiveProxy 支持的 `host-resolver-rules`；无法取得可靠地址时保留原有解析并报告探测失败。
- 保留 2026-1193 的 IPK control/data 归档及目标维护文件 `root:root` 属主修复。

## 安全与升级

不修改设备 DNS、防火墙、路由或 TUN，也不关闭证书验证。运行配置仍为 600，节点目录仍为 700；host-resolver-rules 不包含凭据。升级前保留 `/etc/config/openkill` 与 `/etc/openkill`，失败时可回滚上一正式版 IPK。

## 验证范围

在授权测试机上对真实节点完成 Fake-IP 对照实验：加入运行级 host-resolver-rules 后，通过本机 SOCKS5 访问 HTTPS 返回 204；默认 Fake-IP 路径的 TLS 失败证据保留在执行计划中。候选/正式包安装后仍需复验当前 Mihomo 实例接入。

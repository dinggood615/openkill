# OpenKill 2026-2018

## DNS 转发模式分离与启动恢复修复

- 保持 `enable_redirect_dns=1` 的 dnsmasq → Mihomo 链路；`enable_redirect_dns=2` 由 OpenKill 防火墙把授权客户端 UDP/TCP 53 直接送入 Mihomo DNS 监听，不再经过 dnsmasq。
- 直接模式继续校验双栈监听、入口规则、重定向端口及 Mihomo 进程归属；dnsmasq 配置不会被错误加入直接模式的数据路径。
- 修复自定义域名 DNS 策略生成时 shell 包裹 Ruby 源码的引号错误；生成失败会保留原配置并把脱敏错误写入受保护日志。
- 恢复检查点携带 DNS 前端模式与监听元数据；不兼容或缺少元数据的旧快照不会被当作新模式的快速启动配置。
- 追加回归测试，覆盖两种模式的目标分离、直接模式自定义策略源码安全及恢复契约。

该版本不改变 WAN、用户代理组、节点、订阅、TUN 或其他插件规则。升级及同版本重装保留用户配置。

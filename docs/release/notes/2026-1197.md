# OpenKill 2026-1197

## NaiveProxy 监听诊断

- 补齐通配地址与 IPv6 监听的归属诊断：外部进程占用节点端口时明确报告
  `port-owned-by-other-process`，不再把通配监听降级为含糊的“未知”。
- 保持 PID、运行配置和监听 socket 证据必须同时匹配后才报告本机服务就绪。

本版本延续 2026-1196 的分享链接边界空白修复、纯观测健康检查、端口分配锁和重启后组件证据刷新。节点凭据只保留在设备受保护目录，源码、默认配置、构建缓存和发布包不携带个人节点数据。

## 验证与升级

在授权 OpenWrt x86_64 测试机上复验独立 SOCKS5、双目标 HTTPS、外部通配端口冲突、多实例隔离和当前 Mihomo 的仅回环测试入口。升级前保留 `/etc/config/openkill`、`/etc/openkill` 和 `/etc/naiveproxy`；失败时恢复上一正式包及受保护备份。下载保持 TLS 证书校验，不修改 WAN、DNS、防火墙、路由或 TUN。

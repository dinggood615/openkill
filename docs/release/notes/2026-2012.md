# OpenKill 2026-2012

## IPv6 DNS takeover correctness

- Keeps Mihomo's existing IPv4 loopback DNS listener and uses the verified local
  dnsmasq UDP/TCP frontend for IPv6 firewall-forwarded DNS. This avoids sending
  IPv6 REDIRECT traffic to an IPv4-only socket.
- Adds the missing IPv6 `dstnat` entry jump for firewall-forwarding mode even
  when IPv6 business proxying is disabled.
- Readiness now matches the family-specific rule, parent entry path and actual
  UDP/TCP listener on the same target. A stale rule fragment cannot satisfy the
  check.
- Legacy ip6tables paths fail with an explicit capability error when IPv6 NAT
  support is required but unavailable; they no longer report a false success.
- DNS forwarding help text describes the real IPv4/IPv6 frontend boundary and
  does not imply WAN exposure or a global DNS kill switch.
- No UCI key or user-value migration is required. Existing DNS forwarding and
  privacy keys are preserved; fw3 capability checks are runtime-gated so an
  unsupported IPv6 NAT backend fails closed instead of being silently
  installed or downgraded.

## Validation boundary

The release includes shell/awk listener tests, isolated fw4 rule-path tests,
legacy capability-failure tests, DNS intent tests and LuCI contract tests. The
work was validated locally and in isolated fixtures only. No router, test
platform, iPhone, real-device install, packet capture or live network test was
performed for this release.

Existing user configuration, nodes, subscriptions, credentials and YAML data
are not included in the package or defaults.

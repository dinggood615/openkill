# OpenKill 2026-1150

## NaiveProxy device bridge correction

- Resolve anonymous UCI server sections to stable IDs before preparing or
  stopping NaiveProxy helper instances.
- Load OpenWrt config helpers for direct diagnostics and report the local
  loopback listener only after the generated ports are actually listening.
- Keep the helper in the root group on OpenWrt builds where `nogroup` breaks
  authenticated TLS; the process remains loopback-only and does not own a
  transparent interception path.

The authorized x86_64 test device generated one credential-free SOCKS5 bridge
on `127.0.0.1:11080` and returned HTTP 204 through the supplied endpoint. UDP,
IPv6, streaming unlock and broad LAN packet-path behavior remain unverified.
Credentials are retained only in protected device configuration and are not
included in this release.

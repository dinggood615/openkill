# OpenKill 2026-2005

## 修复

- 修复来源流量规则卡片在 LuCI 延迟初始化/重试时可能重复挂载并触发 `HierarchyRequestError` 的问题。
- 保持规则编辑器使用原始 CBI 节点、字段和提交行为；挂载前增加祖先/后代关系保护，避免 DOM 循环插入。

## 保持不变

- 七个插件设置页的卡片布局、来源流量规则纵向编辑和 2026-2004 的通用初始配置保持不变。
- 本版本不改变 DNS、NaiveProxy、WAN、TUN 或其他网络接管策略。

## 升级与回滚

- 升级和同版本重装保留 `/etc/config/openkill` 及用户数据。
- 如需回滚，安装上一份已校验的正式 IPK，并在确认配置备份可读后恢复对应配置。

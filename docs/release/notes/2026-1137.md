# OpenKill 2026-1137

## NaiveProxy detection and share-link import

- Distinguish the installed OpenKill package from the optional NaiveProxy
  executable, including approved manual-install fallback paths.
- Report executable, version-probe and missing-component states separately;
  no status is inferred from a stale state file alone.
- Extend the existing node URL importer for `naive+https://`,
  `naive+quic://` and `naiveproxy://` links, including IPv6 literals,
  percent-encoded credentials, TLS/transport mapping and unsupported-parameter
  warnings.
- Keep credentials in the protected node form only. Import fills the editor
  and requires the normal save/apply flow; it does not enable nodes, install a
  component, select DIRECT or bypass user policy.
- Preserve loopback-only SOCKS5 bridge generation and `udp: false` until UDP
  support is separately verified.

Validation is local plus authorized device inspection. No remote NaiveProxy
authentication or packet-path test is claimed without a real endpoint test.

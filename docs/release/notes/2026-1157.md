# OpenKill 2026-1157

## NaiveProxy 手动 YAML 接入

- NaiveProxy 辅助组件只维护受保护的远端配置和 `127.0.0.1` SOCKS5 入口；页面不再自动把节点注入 Mihomo 或策略组。
- 新节点使用稳定身份和回环端口，页面提供不含凭据的 SOCKS5 YAML 片段，用户可手动加入自己的 `proxies` 和 `proxy-groups`。
- 旧版自动接入值会保留并显示迁移提示；确认现有桥接节点和策略组引用后，才可切换为手动 YAML，OpenKill 不会静默改写或删除用户 YAML。

## 连接检测与界面

- 逐节点健康检测只通过对应回环 SOCKS5 访问受限制的 HTTPS 目标，区分辅助链路可用、探测失败、未验证和过期结果，不失败直连。
- 组件、节点、辅助进程、本地入口和 YAML 关系分开显示；任务去重、过期缓存及有界 procd 重启避免重复进程和无限重试。
- OpenKill 页面使用统一的作用域底色、卡片、边框和控件层级，保留深色/浅色主题及响应式布局。

## 验证边界与回滚

- 本地 NaiveProxy 健康夹具、集成/UI 合同、POSIX 语法、CSS 预览和 `local-gate` 已通过；精确提交的 Development CI 通过后再执行 RC 与 Formal Release。
- 本版不改变 DNS、IPv6、TUN、防火墙、透明接管、策略组默认选择或 UDP 能力。设备、真实 Naive 服务端、远端认证、UDP/IPv6 业务和多视口浏览器仍需单独验证。
- 如需回滚，安装上一版 `2026-1156` 包并保留现有节点配置；升级前请备份手动 YAML 及策略组引用。

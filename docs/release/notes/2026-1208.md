# OpenKill 2026-1208

## 修复

- 严格 DNS 隐私模式在核心、控制器和本地监听已经就绪后，首次加密 DNS 运行校验遇到瞬时代理或上游延迟时不再立即把服务判定为启动失败。
- 增加三次有界、只读的运行证据重试；持续失败仍保持失败闭锁，不会静默回退到明文 DNS 或 DIRECT。

## 兼容性

- 保持 2026-1207 的 Mihomo v1.19.32 运行配置、mips TUN、BBR3 及 IPv4/IPv6 能力默认值不变。
- 不修改现有节点、用户 YAML、DNS 策略、WAN、防火墙或 TUN 接管配置。

## 升级与回滚

升级后按页面提示重新应用配置；若严格 DNS 上游持续不可达，服务会保留可诊断的失败状态。可安装上一正式版 IPK 并恢复受保护的 OpenKill 配置备份回滚。

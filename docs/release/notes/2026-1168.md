# OpenKill 2026-1168

## 变更

- 优化 RC Build 与 Formal Release 的 OpenWrt SDK 准备流程：按 SDK 版本和
  工作流内容复用经过校验的 SDK、feeds 与宿主工具缓存，减少重复下载、解包
  和准备时间。
- 正式 IPK/可选 APK 构建统一使用 OpenKill 单包 makefile 直接编译，保留包选择
  防护，避免无关 SDK 依赖被聚合目标拉起。
- 缓存只用于缩短准备阶段；源码版本校验、精确提交、包内容审计、SHA256、RC
  及 `release_gate=true`/`publish=true` 正式门禁保持不变。

## 验证边界

本版本通过本地工作流契约测试、POSIX 门禁、`sh scripts/local-gate.sh` 和
`git diff --check`。GitHub Development CI、RC 构建与 Formal Release 将针对
本版本精确提交执行。未进行路由器、真实设备、VPS 或数据包路径验证。

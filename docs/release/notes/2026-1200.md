# OpenKill 2026-1200

## 运行状态页 UI 修复

- 运行状态页的 DNS 隐私、广告拦截、OpenVPN 兼容、RustDesk 和 NaiveProxy
  卡片改为使用后端证据驱动的有限状态：开启、关闭、待验证、异常或未知。
  “已配置”“规则已生成”“组件已安装”不再被误显示为功能已经开启；详细
  证据保留在卡片说明和辅助标签中。
- 修复字符串布尔值被 JavaScript 当作真值的问题，并在独立 NaiveProxy
  清单尚未产生时显示“未知”，避免把组件缺失或未检测误报为关闭。
- IP 地址/访问检查页移除 CBI 外层容器的可见背景、边框和额外间距，保留
  原有检查、刷新和隐私控制，使面板与 OpenKill 内容列对齐并适配窄屏。
- 状态查询新增只读的独立清单存在性字段；不启动服务、不生成配置、不分配
  端口，也不改变 NaiveProxy、DNS、路由、防火墙、TUN 或默认代理策略。

## 验证与升级

已运行 UI 合同、交互、预览、浏览器和本地门禁测试。升级会保留用户配置、
节点、订阅和 YAML；若需回滚，安装上一正式版本并恢复升级前备份。本版本
只修复界面状态与布局，不宣称修复此前独立 NaiveProxy 的网络路径问题。

# OpenKill 2026-2008

## DNS 隐私启动与配置一致性

- 严格 DNS 统一使用同一套上游后缀解析规则，合法的单路由选择器和安全连接参数在生成与运行验证中保持一致。
- 严格模式的专用 DNS 组支持具体代理节点及代理提供者；不会把嵌套组或 DIRECT 隐式加入隐私出站。
- 运行就绪检查优先使用 OpenWrt 必备的 `jsonfilter` 读取控制器响应，不再要求可选的 Ruby JSON 扩展。
- 严格模式的直接加密引导解析在诊断状态中明确标记为引导例外；业务 DNS 仍不允许明文或 DIRECT 静默回退。
- 配置生成失败时保留当前有效配置，检查点只在完整就绪后更新，恢复流程保持有界。

本版本不会打包节点、订阅、密码、控制器密钥、用户 YAML 或设备专用数据。全新安装仍使用设备无关的默认配置；升级和重装保留用户已有配置。

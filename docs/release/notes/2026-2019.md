# OpenKill 2026-2019

## Redir-Host / TUN 管理访问保护

本版本修复 Redir-Host 切换期间局域网管理流量可能被 TUN/防火墙接管链再次捕获的问题，并收紧模式切换后的诊断边界：

- 自定义局域网地址集合现在始终在内置私有、回环、链路本地和管理网段基础上追加，不会因自定义文件遗漏 `192.168.0.0/16` 而失去 LuCI、控制器或 SSH 的本地绕过。
- 当由 Mihomo 原生管理 TUN 自动路由和自动重定向时，生成配置加入与 OpenKill 防火墙路径一致的双栈私有/管理地址排除；OpenKill 自己管理路由时不重复写入该字段。
- `common_ports` 未配置或为 `0` 时不再引用不存在的集合。只有明确填写端口限制时才生成 Redir-Host 的端口例外，避免空策略在 fw4/iptables 上改变路由器自身流量语义。
- IPv4/IPv6 的模式切换、重复应用和失败恢复继续由受管规则清理；配置校验失败仍保留上一个可用配置。

本版本不改变用户节点、订阅、DNS 隐私模式、WAN、TUN 所有权、全网代理组或其他插件策略。电脑端 Clash/VMware 重叠网段仍可能独立影响客户端访问，需在客户端侧排除后再归因于路由器。

回滚：保留并安装上一正式版 `v2026-2018-ipk`，然后按设备上的受保护备份恢复 OpenKill 配置及受管规则；不要删除历史标签或 Release。

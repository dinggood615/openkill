# OpenKill 2026-1203

## Mihomo 专用 DNS 代理组与加密引导

- 严格 DNS 隐私模式生成独立的专用代理组，只引用具体可用代理节点，不继承
  用户代理组中的 `DIRECT`、嵌套组或本地 SOCKS 桥，避免 DNS 旁路和解析循环。
- 普通 `nameserver`、`fallback` 和 direct DNS 明确绑定该组；代理节点和解析器
  引导使用证书校验的 IP 加密 DNS，不再自动补入明文公网解析器。
- provider-only 或无可用具体节点的严格配置会明确失败，保留原运行配置，不静默
  回退到直连。
- 增加启动后的只读运行校验：最终配置指纹、专用组、Mihomo DNS API 查询和核心
  状态必须一致，严格模式验证失败时不报告服务就绪。

## 验证边界与升级

- 测试机验证包括核心配置校验、加密 DNS 查询、HTTPS 出站和有限 WAN 抓包；有限
  抓包不能证明所有客户端 DoH、IPv6 或服务停止后的全局流量绝对无泄漏。
- 升级保留 OpenKill 配置、用户 YAML、节点、订阅、NaiveProxy 独立数据及端口映射。
- 若需要回滚，安装上一正式版并按受保护备份恢复；严格模式运行校验失败时先切回
  原配置，不关闭 TLS 证书校验。

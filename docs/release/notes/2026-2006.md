# OpenKill 2026-2006

## UI 优化

- 调整“网络与分流”卡片顺序：DNS 与本地解析、流量转发位于第一行，IPv6 与 TUN、局域网设备访问控制位于第二行；窄屏保持相同的单列顺序。
- 交换“兼容与辅助”中的“OpenVPN 精确兼容”和“远程访问绕过”卡片位置，保持字段、校验和保存行为不变。
- 统一来源流量规则子区域的主题、边框和字段排版，保留原始 CBI 控件、规则顺序及提交机制。
- 同一桌面网格行内的设置卡片自然等高，移动端恢复内容自适应高度，避免固定高度和无意义留白。

## 保持不变

- 本版本仅调整 LuCI UI 呈现，不改变 DNS、NaiveProxy、服务生命周期、WAN、防火墙、路由、TUN 或全网代理策略。
- 升级和同版本重装保留 `/etc/config/openkill` 及用户数据。

## 升级与回滚

- 使用最新一键安装命令，或明确指定 `--version 2026-2006` 安装已校验的正式包。
- 如需回滚，安装上一份已校验的正式 IPK，并在确认配置备份可读后恢复对应配置。

# OpenKill 2026-1170

## 变更

- OpenKill 页面现在在自身根节点内继承当前 LuCI 主题的语义颜色，提供浅色、深色和旧主题回退；状态页、插件设置、表单控件、卡片、表格和焦点样式保持原有字段、接口及保存应用语义，并在桌面和窄屏下允许内容自然换行。
- 一键安装在 OpenKill 本体之后进入独立 NaiveProxy 组件阶段，依据 OpenWrt 包架构和官方稳定资产目录/API 匹配制品，执行 HTTPS、大小、SHA256、归档、ELF、loader 与 `naive --version` 校验，再原子替换官方二进制。组件失败会与本体结果分开报告并保留旧组件与节点配置。
- 修复官方版本号包含修订后缀时的组件版本记录，并补充官方稳定资产的受校验目录回退，减少首次安装因 `jsonfilter` 缺失或 GitHub API 暂时不可用而误报组件未安装。

## 验证边界

本版本通过 NaiveProxy 独立服务、安装器、导入行为、UI 合同、UI 预览、真实 Chrome 浏览器、POSIX/BusyBox 语法、`sh scripts/local-gate.sh` 和精确提交 Development CI。浏览器证据覆盖 1920、1366、768、390 CSS px，并分别采集深色与浅色计算样式。Windows 主机的直接 PyYAML 测试因环境缺少模块未执行，WSL 中同一测试已通过。未执行测试机写入、真实 VPS 认证、WAN、DNS、中央 nft 或数据包路径测试；这些范围仍待后续明确授权。

- 自动模式继续生成 Mihomo 可用的回环 SOCKS5 节点，不向 Mihomo 写入原生 `type: naiveproxy`。
- 生成器现在记录组件、节点、回环端口、最终 YAML 和策略组引用阶段；条件失败不再静默跳过。

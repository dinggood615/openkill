# OpenKill 2026-2000

这是一次大版本更新，默认值、页面归类和运行态审计同时更新。

## 页面与规则归类

- “来源流量规则”归入“流量转发”卡片，保留原有 UCI section、顺序、校验和增删改行为。
- 规则字段改为“来源地址、来源端口、协议、地址族、入接口、来源用户、DSCP 标记、处理动作”，避免把来源条件误称为内部或出口条件。
- 规则卡片在窄屏使用局部滚动，不改变整个页面的宽度约束。

## 全新安装默认值

全新安装采用经过审计的高性能双栈基线：OpenKill 管理 TUN、mips TUN 栈、IPv4/IPv6 DNS、标准 Geo 数据、TCP 并发、统一延迟、BBR3 字段、QUIC/UDP 关闭、防火墙 DNS 转发和增强 anti-AD 规则。防火墙转发只重定向到已经验证的本机 Mihomo DNS 监听，停止或失败时清理本组件拥有的规则。

严格 DNS 隐私仍不是无节点新装默认值：没有可选择的代理组时严格模式会按设计拒绝就绪，避免首次安装把设备锁死。需要严格模式的用户应先导入可用节点并选择专用 DNS 代理组，再保存并应用。升级、重装和已有 conffile 保留用户明确选择；缺少新字段时只做幂等迁移。

默认值不包含节点、订阅、密码、设备地址、用户 YAML、个人规则或运行状态。

## 运行态审计

- 配置归一化补齐 v1.19.32 相关的双栈、mips、BBR3、Geo、QUIC 和防火墙 DNS 字段，并保持显式用户值。
- anti-AD 规则仍由一份经校验的域名列表生成 dnsmasq 和 Mihomo 两个视图；服务就绪后额外核对 dnsmasq include、Mihomo provider 标记和实际核心进程，只有两者都存在才报告运行态有效。
- BBR3 表示 Mihomo 支持的 TUN/协议字段，不等价于安装 Linux 内核 BBR 模块；安装器不会盲目添加无关内核包。
- IPv4/IPv6 和实验性区域旁路继续依赖设备内核、fw4/fw3 和实际地址集合；不支持的地址族保留为未验证，不以配置文本冒充数据面成功。

## 验证边界、升级与回滚

发布前运行本地行为测试、UI 合同测试、网络/DNS 模型测试和安装器门禁，并在授权测试机上核对包内容、配置保留、核心加载、双栈监听、规则集合和 HTTPS 冒烟。没有可控 LAN 客户端时，客户端 UDP/TCP 53 实际穿过本机的计数不能替代验证；浏览器视觉验收也需在可见 LuCI 会话中完成。

升级前备份 `/etc/config/openkill`、用户 YAML、独立组件数据和自定义规则。升级失败时安装上一正式版 IPK 并恢复备份；不要删除旧标签或旧 Release。

# OpenKill 2026-1188

## NaiveProxy start probe fallback

- Added a protected SHA256-consistency fallback for a transient LuCI/uwsgi
  loader probe mismatch during start.
- The fallback never disables TLS or skips runtime validation: procd must still
  create the real process, pass bounded readiness, and prove listener
  ownership; changed or unverified binaries remain blocked.
- Fixed the component evidence reason when lifecycle success records
  `available`.

The 2026-1187 evidence-stability change and all earlier LuCI transport,
import, lifecycle and Mihomo protections remain included.

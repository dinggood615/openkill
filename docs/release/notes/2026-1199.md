# OpenKill 2026-1199

## 修复

- 修复重新安装或升级后保留旧 `/etc/config/openkill`、缺少 `log_level`
  字段导致生成空 `log-level`，Mihomo 报 `invalid log-level` 并使 OpenKill
  启动失败的问题。
- 配置归一化会为缺失或不支持的日志等级恢复安全默认值 `0`；启动入口也
  对旧配置做防御性校验，避免无效值进入运行配置。
- 保留用户配置、订阅、规则、YAML、Naive 独立组件和自定义文件。

## 升级与回滚

升级后首次启动会自动补齐缺失的日志等级字段。若启动仍失败，请查看
`/tmp/openkill_start.log` 中的具体校验阶段。回滚时安装上一正式版本并恢复
升级前的受保护配置备份。

本版本未改变 WAN、DNS、防火墙、路由或 TUN 策略。

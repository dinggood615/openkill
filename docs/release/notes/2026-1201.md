# OpenKill 2026-1201

## 运行状态与 DNS

- 运行状态页的 IP 地址/访问检查区域改用与上方状态区域相同的内容列，移除
  CBI 外层产生的黑色横条、额外背景和宽度收缩；内部检查卡片和按钮行为保持不变。
- DNS 隐私、广告拦截、OpenVPN 兼容、RustDesk 和 NaiveProxy 卡片只呈现
  `已开启` 或 `已关闭`；请求失败时在卡片外显示上次可靠结果提示，首次没有可靠结果时
  不伪造二元状态。状态接口保持只读。
- 严格 DNS 模式现在生成加密普通 nameserver/fallback，记录无凭据的状态证据；在
  IPv4-only 严格模式下补齐 fw4 IPv6 DNS 入口并过滤 AAAA，避免 IPv6 DNS 绕过。
  节点/代理引导解析仍作为明确的 bootstrap 例外记录，不改变 WAN、路由、TUN 或全网代理策略。

## 验证与升级

- 通过本地运行时、UCI 生命周期、UI 合同/预览/浏览器和集成门禁；在授权 OpenWrt
  x86/64 测试机验证服务重启后 DNS 状态、IPv4/IPv6 规则和 UDP/TCP 查询行为。
- 升级保留用户配置、节点、订阅、YAML 和 Naive 独立数据；回滚时安装上一正式版并
  按备份恢复配置。外部客户端 DoH、完整 IPv6 数据面抓包及 Chrome 原生会话若不可用，
  仍需在相应环境单独复验。

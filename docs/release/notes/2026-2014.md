# OpenKill 2026-2014

## Proxy-group health checks

- The OpenKill-managed health-check default is now `https://cp.cloudflare.com/generate_204`.
  It remains HTTPS and expects status 204; user-selected URLs, expected statuses and
  cadence values are preserved.
- Existing profiles are migrated only when they contain the exact legacy OpenKill
  gstatic probe tuple and no URL-Test override is selected. Provider health checks
  receive the same idempotent migration so provider-backed members and their groups
  report the same real delay. A non-zero URL-Test override remains authoritative.
- Strict DNS's managed health group, the shipped sample profiles and the streaming
  helper fallback use the same current endpoint. No node, subscription, credential,
  business rule, default proxy selection or network policy is changed.

## Verification boundary

- Local health-default and DNS privacy regressions cover custom endpoint preservation,
  legacy migration, provider health metadata and strict-group generation.
- Device evidence for this release is limited to the authorized router's controller
  API and service state. Node names, addresses, credentials and complete YAML are
  intentionally omitted from public records.

# OpenKill 2026-2003

## 本次更新

- 优化“插件设置”七个子页面的卡片节奏：内容按实际字段自适应，短卡片不再被相邻卡片拉伸，桌面双列与窄屏单列保持统一间距和对齐。
- 修复“流量转发”中的“来源流量规则”编辑器：标题、说明和规则选项恢复可见，字段标签按真实控件名称生成，规则以纵向卡片展示，保留原有 UCI 键、排序、校验和提交行为。
- 增加 `performance-dual-stack` 全新安装默认配置标识。默认值只包含设备无关的通用能力，不包含节点、订阅、密码、用户 YAML、设备地址或个人规则。
- 升级、同版本重装和归一化迁移继续保留用户已有配置；只为缺失字段补充默认值。

## 使用与回滚

- 全新安装会使用新的通用默认配置；已有安装无需重新导入节点或订阅。
- 安装后如需应用页面变更，按 LuCI 的“保存配置”及“应用配置”顺序操作；本版本不改变 DNS、NaiveProxy、WAN、TUN 或其他网络接管机制。
- 回滚时安装上一正式版 IPK；OpenKill 的用户配置文件按现有 conffile 规则保留。如需恢复页面资源，先停止服务并使用安装前的受保护备份。

## 验证范围

- 本地 WSL 门禁、运行时、UCI 生命周期、安装器、LuCI 合同、预览/交互/浏览器模板检查通过。
- RC 与正式包仍需在授权测试机完成页面视觉、来源规则 CRUD、配置保留和正式包安装验收后，才能将设备状态记为已验证。

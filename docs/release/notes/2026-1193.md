# OpenKill 2026-1193

## 修复

- 修复正式 IPK 在非 root SDK 用户构建时继承数字属主的问题。
- 发布前统一规范 control/data 归档及目标设备上的 OpenKill 维护文件为 `root:root`，避免 `/etc/init.d/naiveproxy-bridge` 和新增 conffile 以构建用户属主安装。
- 保留 NaiveProxy 独立服务的请求文件控制、增量 procd 实例启动和凭据保护修复。

## 升级与回滚

升级前保留 `/etc/config/openkill` 及 `/etc/openkill`。安装后如需回滚，使用上一正式版 IPK，并保留当前配置文件；安装脚本会按现有 conffile 规则处理用户修改。

## 验证范围

本版本在授权测试机上验证正式包可重装、独立 Naive 进程和回环监听保持运行。远端分享节点的 HTTPS 连通性及当前 Mihomo 运行实例接入仍需以设备现场网络结果为准，不以组件版本或监听状态替代远端验证。

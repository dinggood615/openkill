# OpenKill 2026-1191

## LuCI 控制通道

- LuCI 控制请求改用权限为 0600 的一次性输入文件，避免把 uWSGI 写管道继承给独立 NaiveProxy 进程；该管道在测试机上会导致官方进程启动后触发 SIGTRAP。
- 每个请求使用独立的受保护结果文件，避免多页面并发时共享 `control.result` 互相覆盖。
- 仍由独立脚本返回阶段和退出码；凭据不进入命令参数、普通状态或日志。

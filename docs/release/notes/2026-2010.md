# OpenKill 2026-2010

## DNS 分层与国内业务分流

- 严格 DNS 隐私继续由单一生成器绑定专用加密 DNS 出站组；业务流量规则不再因解析传输方式而整体走代理。
- 在 rule 模式且启用国内地址族分流时，如果用户没有显式的中国域名/IP决策，生成器会在最终匹配规则前幂等补入标准的国内直连规则。
- 用户已经配置的中国域名/IP规则保持原顺序和目标，不会被默认规则覆盖。
- 生成失败仍保留上一份有效配置；严格模式不会静默回退到明文 DNS 或 DIRECT 上游。

## 广告屏蔽

- DNS 屏蔽与 Mihomo 规则使用同一份经过 HTTPS 下载、规范化和原子替换的域名缓存。
- 允许列表、用户阻止列表、RustDesk/OpenVPN 必要例外和更新失败保留旧列表的行为保持一致；运行状态仅在实际 dnsmasq 与当前配置对应的核心进程加载后标记为有效。

本版本不包含节点、订阅、密码、控制器密钥、用户 YAML 或设备专用数据。升级和重装保留用户配置；全新安装使用设备无关的通用默认值。

# OpenKill 2026-1143

本版本修复 NaiveProxy 节点入口跳转：

- “添加或导入 NaiveProxy 节点”会打开当前已选 YAML 配置对应的代理节点管理页，不再落到 YAML 文本编辑器。
- 从该入口新增代理时预选 NaiveProxy 类型；现有节点类型、配置文件及策略组不变。
- 节点管理链接对配置文件路径进行编码；没有有效配置文件时提示先选择配置。

NaiveProxy 分享链接仍由现有节点编辑器解析。保存节点后需按用户意图启用并加入策略组；本次更新不会自动启用节点、选择 DIRECT 或改变 DNS、防火墙及透明接管策略。真实远端认证和业务流量尚未验证。

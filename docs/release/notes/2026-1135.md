# OpenKill 2026-1135

## Changes

- Harden the NaiveProxy official-release metadata reader by validating the
  release tag before using it to select an asset through `jsonfilter`.
  Unexpected upstream tag data now fails closed instead of being interpreted
  as part of a selector expression.

## Migration and compatibility

- This is a compatible maintenance fix for the NaiveProxy component discovery
  added in 2026-1134. Existing URL/SHA256 values, nodes, subscriptions and
  all unrelated DNS, routing and UI settings are preserved.
- A release with an invalid tag is shown as unavailable and never fills or
  installs a component. The previous `v2026-1134-ipk` release remains a
  rollback option.

## Validation scope and limitations

- Local NaiveProxy integration, POSIX syntax, local-gate, the exact-commit
  Development CI, RC package audit and Formal Release gate must pass for this
  version.
- No device installation or remote NaiveProxy authentication was performed;
  live component loader and endpoint behavior remain device-dependent.

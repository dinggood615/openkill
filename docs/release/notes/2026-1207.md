# OpenKill 2026-1207

## Mihomo v1.19.32 适配

- 将 Mihomo TUN 的 `mips` 协议栈纳入 OpenKill 的默认运行配置，并提供
  `bbr3` TCP 拥塞控制参数；仅在实际核心支持时输出该字段，旧核心使用有界兼容回退。
- IPv4 与 IPv6 共享同一套实际 TUN 协议栈选择，新增配置迁移标记，避免升级后的
  默认值与生成配置不一致。
- 旧配置首次启动时将历史 `system/mixed` 默认组合迁移到 v1.19.32 运行档案；
  迁移只执行一次，之后保留用户明确修改的值。

## 能力归类

- 移除 H2C、ShadowQUIC、MASQUE、AmneziaWG、AnyTLS metadata、BBR3 和内置
  ZeroTier 节点的全局能力门槛。协议字段由节点类型和实际应用场景决定，旧 UCI
  键保留用于升级兼容。
- “Mihomo 能力”页面改为只读的核心与兼容状态，协议参数回到节点编辑页，避免
  将功能散落成默认关闭的全局开关。
- 保留 AnyTLS metadata、0-RTT 及服务端相关参数的安全边界，不会因为核心升级
  自动发送隐私字段或修改用户网络接管策略。

## 验证范围

- 通过 OpenKill 本地质量门禁、运行时行为测试、安装/迁移测试及 LuCI 合同测试。
- 使用官方 Mihomo v1.19.31 与 v1.19.32 完成 TUN、控制器、HTTP 代理和本地 DNS
  冒烟验证；真实设备、候选包和正式包验收结果在发布门禁完成后补入执行计划。

回滚：安装上一正式包 `v2026-1206-ipk`，或恢复升级前保存的 OpenKill 配置与核心备份。

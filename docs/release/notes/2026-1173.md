# OpenKill 2026-1173

## 变更

- 修复生产影子审计夹具的真实缺陷：安全读取隔离路由集合，建模由 init
  脚本提供的 OpenVPN 与路由集合辅助函数，避免把有效路由误判为空或把内部
  API 误报为未知命令。该修复只影响开发期记录模型，不执行 OpenVPN、nft、UCI
  或网络命令，也不改变设备上的网络策略。
- 保留 NaiveProxy 独立服务、凭据隔离、手动 SOCKS5 YAML 接入和现有 OpenKill
  配置语义；未自动写入用户 YAML、策略组、DNS、路由或 DIRECT 选择。

## 验证边界与回滚

- 本地快速门禁 19/19 通过，包含生产影子、NaiveProxy 集成、UI 合同、真实
  生产模板浏览器预览、POSIX/BusyBox 检查、`local-gate` 和差异检查。
- 浏览器证据为本地模板与模拟后端；未执行测试机写入、独立组件安装、真实
  NaiveProxy 二进制探测、VPS 认证、WAN/DNS、中央 nft 或数据包路径测试。这些
  仍标记为设备待验证／远端待验证。
- 如需回滚，安装上一版 `v2026-1172-ipk`，保留现有节点、凭据和手动 YAML。

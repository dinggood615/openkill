# OpenKill 2026-1138

## NaiveProxy xz archive installation

- Add the OpenWrt `xz` runtime dependency required by the official NaiveProxy
  `.tar.xz` assets.
- Decode the verified archive before validating members and extracting the
  executable, including on BusyBox systems whose `tar` lacks xz support.
- Preserve the existing HTTPS allow-list, SHA256 check, archive traversal
  check, ELF/architecture/version probe and atomic replacement behavior.

This release does not enable NaiveProxy automatically. Component installation,
node authentication, local SOCKS5 readiness and remote business verification
remain separate states. Device validation is limited to the authorized test
router and does not claim packet-path or remote authentication success.

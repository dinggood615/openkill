# OpenKill 2026-2007

## 严格 DNS 隐私

- 修复严格隐私生成路径将 `#RULES` 与专用 DNS 代理组叠加、继而误报“DNS 上游选择器歧义”的问题。严格模式现在由单一转换路径绑定 `OpenKill-DNS`，并保留经核准的连接参数。
- 显式的用户代理组或接口选择器不再被静默覆盖；严格模式会拒绝该冲突并保留当前有效配置。
- 运行验证使用已知有效域名并区分 DNS 协议状态、HTTP/控制器错误和配置错误；失败原因写入受保护的临时状态，恢复日志区分“无快照”“快照不兼容”和“已恢复仍失败”。

## 初始设置

- 全新安装采用经过测试机审计的通用双栈性能配置：Mihomo mips、BBR3、IPv6 DNS、增强广告规则、严格 DNS 隐私与防火墙 DNS 转发。
- 默认值不包含节点、订阅、代理组成员、密码、用户 YAML、设备地址、接口、端口映射、缓存或运行状态。升级和同版本重装仅补缺失字段，不覆盖用户选择。
- 没有有效核心或配置文件的新安装保持待配置状态；不会为启动而降级为明文 DNS 或 DIRECT。

## 升级与回滚

- 使用最新一键安装命令，或明确指定 `--version 2026-2007` 安装已校验的正式包。
- 如需回滚，安装上一份已校验的正式 IPK，并在确认配置备份可读后恢复对应配置。

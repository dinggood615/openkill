# OpenKill 2026-1161

## VPN policy and independent NaiveProxy controls

- Device and bypass-router compatibility settings now render inside the
  `VPN 访问策略` card while retaining their existing UCI names, defaults and
  dependency rules.
- The compatibility page presents NaiveProxy as an equal-width independent
  service card with start/stop, add/import, per-node health tests, status
  refresh, diagnostics and credential-free SOCKS5 YAML export.
- Node credentials and lifecycle remain owned by `naiveproxy-bridge` under
  `/etc/naiveproxy` and `/var/run/naiveproxy`; OpenKill does not write them to
  UCI, process arguments or the selected Mihomo YAML.

## Verification limits

Local POSIX syntax, standalone and integration contracts, UI contracts,
interaction tests, `git diff --check` and the local gate passed for the source
commit. Device installation, browser rendering, real VPS authentication and
packet-path tests remain unverified under the current execution plan.

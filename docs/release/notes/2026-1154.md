# OpenKill 2026-1154

## 一键安装恢复

- 为可选数据库刷新增加单次全局时间预算。GitHub/jsDelivr 在设备网络中不可达时，安装器会保留包内数据库并继续完成安装，不再逐个镜像长时间等待。
- 更新或修复前若 OpenKill 已在运行，成功的一键安装会恢复原有运行状态；首次安装或原先已停止的服务不会被强制启动。
- NaiveProxy 组件安装仍保持独立、可选和失败不阻断 OpenKill 的合同。完整 URL/SHA256 绑定存在时可直接进入安装任务；元数据不可达时不会猜测资产。

# OpenKill 2026-1163

## 变更

- 修复“兼容与辅助”中 NaiveProxy 独立服务未进入卡片网格的问题。它现在位于 OpenVPN 精确兼容右侧，并在窄屏按阅读顺序显示。
- 旧 OpenKill NaiveProxy 设置不再作为独立服务状态或安装的来源。升级会先在受保护的本机备份中保存旧项，再仅清理旧 Naive 字段和旧节点；不会复制凭据、改写 YAML 或删除其他协议节点。
- 一键安装在安装 OpenKill 后预检包架构、加载器与组件条件，再匹配并校验官方 NaiveProxy 制品。无可验证匹配时会明确报告独立组件阶段失败，并保留原组件。
- “导入链接”改为链接优先的独立弹窗：先粘贴并解析，再显示脱敏预览；独立服务会再次解析和校验后才保存。手动添加仍保留单独表单。

## 验证边界

本版本通过本地独立服务、链接解析、安装器、LuCI 合同、POSIX 语法和仓库门禁。浏览器渲染环境缺少 Playwright；真实设备、VPS 认证及数据包路径未在本批执行。升级前会保留受保护的旧 Naive 配置备份，用户管理的 YAML 不会被修改。

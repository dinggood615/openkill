# OpenKill 2026-1171

## 变更

- 修复独立 NaiveProxy 组件安装在精简 BusyBox 系统上的预检查：不再要求
  `od` 必须作为独立命令存在，而是选择可用的 `od`、`hexdump` 或 BusyBox
  applet 字节读取器。
- 独立服务的分享链接编码、ELF 魔数、架构检查和安全安装仍然必须完成；
  如果系统没有任何字节读取能力，会以 `missing-byte-reader` 明确失败，
  不会跳过校验或误报安装成功。
- 保留 OpenKill 与 NaiveProxy 独立组件的分阶段结果、旧二进制和节点配置，
  不修改用户 YAML、订阅、DNS 或分流策略。

## 验证边界

修复提交通过独立服务、安装器、导入行为、POSIX/BusyBox 语法和精确
Development CI；另有隔离安装夹具验证在没有 `od`、只有 `hexdump` 时仍可完成
归档、ELF 和架构检查。未执行测试机写入、真实 VPS 认证、WAN、DNS、中央 nft
或数据包路径测试；这些范围仍待后续明确授权。

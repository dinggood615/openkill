# OpenKill 2026-1144

本版本统一 OpenKill 页面排版并精简高频提示：

- 统一状态页与设置页的卡片间距、圆角、标题行距和辅助文字样式。
- 设置说明压缩为短句，保留安装、应用、验证和失败等关键状态差异。
- NaiveProxy 组件检测提示更简洁，长文本支持换行，移动端自然转为单列。
- 广告状态使用“待验证”等准确文案，不把配置存在误写为实际拦截已验证。

本版本不改变 DNS、IPv6、TUN、区域绕过、广告规则、RustDesk、OpenVPN、NaiveProxy 节点、分流和启动恢复策略。浏览器运行时不可用的环境未宣称完成渲染验证；设备远端连接仍需独立验证。

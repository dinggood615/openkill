# OpenKill 2026-1139

## NaiveProxy component installation on BusyBox

- Keep the official `.tar.xz` asset flow and add the OpenWrt `xz` runtime
  dependency.
- Decode and validate the archive before extraction on targets whose BusyBox
  `tar` lacks xz support.
- Use `od` when available and BusyBox `hexdump` as the ELF header fallback;
  this supports the Kwrt x86/64 test image without weakening architecture or
  executable probes.
- Preserve digest, archive traversal, loader/version probe and atomic
  replacement checks. Installation remains explicit and does not enable a
  Naive node or claim remote authentication.
